# Project Overview

**Goal:** Analyze synthetic e-commerce orders and produce reliable business summaries.

**Workflow:** Raw orders → validation checks → completed-order filtering → monthly/category/region KPIs → CSV summaries and revenue chart.

**Business metrics:** Completed orders, unique customers, recognized revenue, estimated profit, average order value, and cancelled/returned share.

**Why it matters:** A report is only useful if its business rules are clear and the numbers can be reconciled. This project demonstrates both analysis and basic data-quality controls.
